|---|---|

- 지금 원고는 APA 7 저자-연도 인용(biblatex)을 씁니다. 참고문헌 정본은 원고 서브모듈의 `Config/references.bib`이고, 옛 번호와 bib 키의 대응은 `Config/refmap.csv`에 있습니다.
- PDF를 받으면 md의 「로컬 저장 시 파일명」대로 이 폴더에 둡니다.
